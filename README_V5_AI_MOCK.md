# CarWise Frontend V5 - AI Mock Data + Multimodal Visual Demo Pack

This is an additive fixture-first layer for visual development. It includes AI vision, copilot, evidence, market, repair, inspection, trust, motion, and demo fixtures, plus the `AIShowcaseV5` screen.

Use the fixtures only for visual QA and demo states. Replace them progressively with selectors over the existing inspection state and API clients. Do not ship mock findings, prices, URLs, or async services as customer-facing production results.

The repository exposes the showcase through the development-only `ai-lab-v5` route. It is not part of consumer navigation.
